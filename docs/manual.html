LiveBindings Visual com Binding Expressions

Manual técnico completo e guia de referência para desenvolvimento de interfaces reativas e desacopladas no Lazarus Component Library (LCL) e Free Pascal Compiler (FPC).

Autor: Engenharia de Software Data: Outubro de 2026 Licença: LGPL com linking exception

1. Arquitetura Modular de Pacotes

A suíte segue rigorosamente as diretrizes arquiteturais de componentes do Lazarus, modularizada em dois pacotes independentes para separar com perfeição o código binário final da infraestrutura de design da IDE:

⚙️
pkg_livebindings_runtime.lpk
Pacote RunAndDesignTime que contém o motor de execução, parsing de expressões com fpexprpars, conversão dinâmica de RTTI e classes fundamentais (TBindingManager, TBindingLink, TBindingLinks). Incluído na sua aplicação final.
🎨
pkg_livebindings_designtime.lpk
Pacote exclusivo DesignTime instalado diretamente na IDE do Lazarus. Fornece a janela dockable LiveBindings Designer, integração com o menu de contexto ("Vincular com LiveBinding..."), property editors dropdown e o diálogo construtor de expressões.
Arquivo Pacote Função / Responsabilidade
uBindingRuntime.pas Runtime Motor de sincronização RTTI, parser de expressões e classes de dados.
uLiveBindingsRegister.pas Designtime Registra componentes na paleta, comandos de menu e criadores de janela.
uBindingPropEditors.pas Designtime Editores de propriedade dropdown e modal para o Object Inspector.
uBindingComponentEditor.pas Designtime Component editor de clique direito no formulário ("Vincular com LiveBinding...").
uBindingDesignerForm.pas Designtime Formulário dockable integrado com GlobalDesignHook e IDEWindowCreators.
uBindingExpressionDialog.pas Designtime Diálogo modal construtor e validador de expressões com catálogo de funções.

2. Instalação e Reconstrução da IDE

✓ Estado Atual da Instalação
Os pacotes já foram integrados e compilados com sucesso no seu executável oficial em C:\lazarus\lazarus.exe.

Processo Automatizado Realizado:

  1. Registro de Links: Ambos os pacotes foram linkados no registro de pacotes do Lazarus via lazbuild --add-package-link.
  2. Instalação do Pacote Designtime: O pacote pkg_livebindings_designtime.lpk foi registrado para instalação permanente.
  3. Reconstrução do Executável da IDE: A IDE foi completamente reconstruída com --build-ide, gerando o novo C:\lazarus\lazarus.exe com os componentes e janelas embutidos.

Reconstrução Manual (se necessário no futuro):

# 1. Registrar os pacotes no Lazarus
lazbuild --add-package-link "runtime\pkg_livebindings_runtime.lpk"
lazbuild --add-package-link "designtime\pkg_livebindings_designtime.lpk"

# 2. Instalar o pacote de design e reconstruir o Lazarus
lazbuild --add-package "designtime\pkg_livebindings_designtime.lpk" --build-ide=

3. Componentes Centrais

TBindingManager

Componente não-visual que atua como o regente e orquestrador de todos os vínculos em um formulário ou TDataModule.

  • Links: TBindingLinks: Coleção tipada gerenciando cada regra de ligação, com suporte a persistência nativa em arquivos .lfm.
  • AutoSyncOnLoaded: Boolean: Quando True (padrão), efetua a sincronização total automática assim que o formulário é carregado em tempo de execução.
  • Active: Boolean: Liga ou desliga globalmente todas as sincronizações do gerenciador.
  • Notification: Escuta a destruição de componentes e limpa referências órfãs automaticamente, garantindo integridade de memória.

TBindingLink

Cada item individual da coleção Links, representando a ponte entre uma origem e um destino.

Propriedade Tipo Descrição
Source TComponent Componente provedor do dado inicial.
SourceProperty string Nome da propriedade RTTI do Source (no modo bmDirectProperty).
SourceExpression string Fórmula dinâmica avaliada pelo fpexprpars (no modo bmExpression).
Target TComponent Componente que receberá o valor calculado ou transferido.
TargetProperty string Nome da propriedade RTTI do Target onde o dado será gravado.
Direction TBindingDirection bdSourceToTarget (padrão), bdTargetToSource ou bdTwoWay.
Mode TBindingMode bmDirectProperty ou bmExpression.
Active Boolean Ativa ou pausa este vínculo específico.
FormatMask string Máscara opcional de formatação (ex: R$ #,##0.00, %d%%).

4. Modos de Operação e Coerção RTTI

Modo 1: Vínculo Direto (bmDirectProperty)

Transfere o valor lido da propriedade do componente Source diretamente para a propriedade do componente Target. O motor conta com um avançado conversor de tipos via RTTI:

  • Inteiro para String: Converte automaticamente (ex: TTrackBar.Position -> TLabel.Caption).
  • String para Inteiro / Float: Executa conversão segura com tratamento de valores padrão.
  • Booleano para Estado: Converte True/False para propriedades de visibilidade ou habilitação (ex: TCheckBox.Checked -> TButton.Enabled).
  • Enumerações: Suporte a leitura de nomes ordinais e escrita compatível com símbolos de enumeração.

Modo 2: Vínculo por Expressão Dinâmica (bmExpression)

Calcula o valor do destino através do motor fpexprpars. As propriedades publicadas do componente de origem são automaticamente transformadas em variáveis locais no escopo do cálculo.

5. Motor de Expressões Dinâmicas (fpexprpars)

Ao calcular uma expressão, o LiveBindings identifica dinamicamente o tipo de cada propriedade e a registra como variável tipada no parser (AddFloatVariable, AddStringVariable, AddBooleanVariable, AddIntegerVariable).

Identificadores Automáticos:

  1. Propriedades do Source: Usadas diretamente pelo nome da propriedade: 
    // Se Source for um TFloatSpinEdit com propriedade "Value":
Value * 1.20

// Se Source for um TEdit com propriedade "Text":
Upper(Text)

// Se Source for um TCheckBox com propriedade "Checked":
If(Checked, "CLIENTE VIP", "REGULAR")
  2. Componentes Irmãos no mesmo Formulário: Acessíveis através da sintaxe Componente_Propriedade: 
    // Multiplicação combinando dois controles diferentes do form:
Value * seQtd_Value * 1.15

// Concatenação de dois TEdits:
Upper(Trim(Text)) + ' ' + Upper(Trim(edtSobrenome_Text))
💡 Formatação com FormatMask
Se o destino for um campo textual (como TLabel.Caption ou TEdit.Text), você pode preencher a propriedade FormatMask do vínculo. A formatação de moeda (ex: R$ #,##0.00) ou percentual (ex: %d%%) será aplicada automaticamente após a avaliação da fórmula!

6. LiveBindings Designer (Janela Dockable)

A ferramenta visual é acessada em Exibir -> Janelas Secundárias -> LiveBinding Designer ou clicando com o botão direito em qualquer controle e selecionando "Vincular com LiveBinding...".

🌳
Árvore de Componentes (Esquerda)
Lista todos os componentes do formulário em edição ativa na IDE. Expanda para ver cada propriedade RTTI publicada e seu respectivo tipo de dado. Filtro rápido por texto no topo.
📋
Grade de Vínculos (Direita)
Tabela exibindo todos os vínculos ativos do TBindingManager. Mostra status, origem, expressão ou propriedade, direção, destino e modo. Permite editar expressões com duplo clique.

Barra de Ações Rápidas:

  • 🔗 Vínculo Direto: Conecta a propriedade marcada como Origem com a propriedade marcada como Destino.
  • ⚡ Vínculo Expressão: Abre o construtor de expressões e adiciona o cálculo ao gerenciador.
  • ✏️ Editar Expressão: Abre o diálogo para alterar a fórmula do vínculo selecionado.
  • 🗑️ Excluir: Remove o vínculo selecionado com confirmação.
  • ✔️ Ativar/Desat.: Alterna o estado ativo do vínculo.
  • 🔄 Sincronizar: Força a sincronização imediata do vínculo selecionado.

7. Construtor Modal de Expressões

O diálogo modal TBindingExpressionDialog proporciona um ambiente completo e seguro para montagem de fórmulas em tempo de design:

  • Editor com Destaque: Campo Memo com fonte monoespaçada e posicionamento inteligente de cursor.
  • Lista de Propriedades Disponíveis: Com duplo clique, insere o identificador exato da propriedade no texto da fórmula.
  • Catálogo de Funções fpexprpars: Separado por categorias (Matemática, Strings, Lógica, Data/Hora, Conversão). Ao dar duplo clique em uma função (ex: UPPER(S)), ela é inserida e o cursor é automaticamente posicionado dentro dos parênteses.
  • Botão "⚡ Testar Expressão": Avalia a fórmula em tempo real usando as propriedades do formulário. Se estiver correta, exibe em verde o tipo e o valor computado; se houver erro de sintaxe, exibe a mensagem de diagnóstico exata em vermelho.

8. Property Editors no Object Inspector

A integração com a paleta de propriedades do Lazarus oferece comodidade máxima:

🔽
TBindingPropertySelectorEditor
Dropdown inteligente para SourceProperty e TargetProperty. Inspeciona o componente configurado e exibe apenas as propriedades compatíveis (legíveis para origem, graváveis para destino).
🔍
TBindingExpressionEditor
Editor de diálogo para SourceExpression. Exibe o botão de reticências [...] no Object Inspector para invocar o Construtor Modal de Expressões.

9. Programação em Tempo de Execução (Runtime API)

Todos os recursos visuais do LiveBindings podem ser manipulados programaticamente com pouquíssimas linhas de código Pascal:

Exemplo 1: Vínculo Direto via Código

uses
  uBindingRuntime;

var
  Link: TBindingLink;
begin
  // Cria vínculo: Edit1.Text -> Label1.Caption
  Link := BindingManager1.AddLink(Edit1, 'Text', Label1, 'Caption');
  Link.Active := True;
  Link.Synchronize;
end;

Exemplo 2: Vínculo por Expressão com Máscara Monetária

var
  Link: TBindingLink;
begin
  // Calcula o total com acréscimo de 15%
  Link := BindingManager1.AddExpressionLink(
    sePreco,
    'Value * seQtd_Value * 1.15',
    lblTotalComImposto,
    'Caption'
  );
  Link.FormatMask := 'R$ #,##0.00';
  Link.Active := True;
  Link.Synchronize;
end;

Exemplo 3: Expressão Condicional e Tratamento de Eventos

procedure TForm1.FormCreate(Sender: TObject);
begin
  // Captura de eventos para auditoria e logs
  BindingManager1.OnAfterSync := @DoLogSync;
  BindingManager1.OnBindingError := @DoTratarErro;

  // Vínculo condicional
  BindingManager1.AddExpressionLink(
    chkAtivo,
    'If(Checked, "SISTEMA OPERACIONAL", "SISTEMA PAUSADO")',
    lblStatus,
    'Caption'
  );
end;

procedure TForm1.DoTratarErro(Sender: TObject; Link: TBindingLink; const ErrorMsg: string);
begin
  WriteLn('[Falha na Expressão] ' + Link.DisplayName + ': ' + ErrorMsg);
end;

11. Catálogo Completo de Funções fpexprpars

Função Retorno Parâmetros Descrição e Exemplo
UPPER(S) String String Converte texto para maiúsculas. Ex: Upper(Text)
LOWER(S) String String Converte texto para minúsculas. Ex: Lower(Text)
TRIM(S) String String Remove espaços antes e depois do texto. Ex: Trim(Text)
IF(Cond, S1, S2) String Boolean, String, String Retorna S1 se Cond for verdadeiro, senão S2. Ex: If(Ativo, 'Sim', 'Não')
IFNUM(Cond, N1, N2) Float Boolean, Float, Float Retorna N1 se verdadeiro, senão N2. Ex: IfNum(Vip, Preco*0.8, Preco)
ROUND(X) Integer Float Arredonda para o inteiro mais próximo. Ex: Round(Valor)
TRUNC(X) Integer Float Trunca a parte decimal do número. Ex: Trunc(Valor)
ABS(X) Float Float Retorna o valor absoluto positivo. Ex: Abs(Saldo)
SQRT(X) Float Float Calcula a raiz quadrada de X. Ex: Sqrt(Area)
FORMATFLOAT(M, N) String String, Float Aplica máscara numérica. Ex: FormatFloat('#,##0.00', Total)
NOW DateTime Nenhum Retorna a data e hora do sistema. Ex: Now
FORMATDATETIME(M, D) String String, DateTime Formata data. Ex: FormatDateTime('dd/mm/yyyy', Now)
LENGTH(S) Integer String Retorna a quantidade de caracteres. Ex: Length(Senha)
COPY(S, Ini, Qtd) String String, Int, Int Extrai trecho de texto. Ex: Copy(Codigo, 1, 3)
